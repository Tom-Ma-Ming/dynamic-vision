# 编码器反馈传输

新增默认关闭encoder_transport；要求encoder_compensation。encoder_delay_ms固定回传延迟0～10000ms；encoder_drop_rate为0～1；encoder_drop_end_frame=-1为全窗口，否则仅此前丢包；encoder_max_age_ms为0.001～10000ms。独立随机种子，不改变原视觉/命令随机序列。

累计位移与采样时间一起发送；在途与已接收历史各最多256项，满时删除最老项，记录传输溢出。只可使用已经接收的样本，最新样本超过年龄门槛即不可用。仿真与传感器共用纳秒时钟；不模拟设备时钟偏移。

启用时，视觉发布等待对应帧编码器的预定到达时间。缺失或被有界历史淘汰的样本，导致对应观察记录encoder_missing并不送入跟踪器；这是严格配对策略，未实现无编码器视觉降级。推理检测计数仍保留，不能把未发布观察当作检测漏检。历史运动补偿从已接收的配对样本读取；向当前时刻补偿只使用最新已接收样本，不使用理想实时累计位移。未配对初始化或样本过期时control_gate=encoder_unavailable，停止生成动作、按现有本地不可控分支取消命令；新鲜配对样本回来后允许恢复，不等于命令反馈故障的显式重同步。

本改动没有估计最后一次编码器采样至当前的未知运动，因此延迟下仍可能控制不准。既有固定时间步场景、断连和本地取消模型保留；真实encoder、回传乱序/抖动、独立时钟及实际异步调度未验收。

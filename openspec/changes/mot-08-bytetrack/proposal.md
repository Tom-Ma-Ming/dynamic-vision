# MOT-08 低置信度二次关联（ByteTrack 风格）

## 目标

在不改变默认跟踪行为的前提下，增加一个可回滚的实验开关：先用高置信度检测做第一轮关联，再用低置信度检测只对未匹配的已确认/暂失轨迹做第二轮关联；低置信度检测永远不能创建新轨迹。

## 范围

- `Config` 增加 `byte_track`、`high_score`、`low_score`，默认关闭/0.4/0.1。
- `Tracker::update` 增加第二关联分支；默认分支保持原逻辑。
- `vision_replay` 在 `byte_track=1` 时把检测阈值降到 `low_score`，让低置信度框进入跟踪器。
- SIM-01 增加低置信度观测场景，比较基准与 ByteTrack。
- 单元测试覆盖：低置信度不能确认 Tentative、不能新建轨迹；已确认轨迹可被低置信度二次关联保持。

## 非目标

- 本轮不实现 IMM、镜头补偿或 ReID；这些继续作为后续实验。
- 不改变检测模型、NMS、Engine 或默认阈值。

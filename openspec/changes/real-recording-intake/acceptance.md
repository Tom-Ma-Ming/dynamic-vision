# 验收条件

| 输入 | 动作 | 要求 |
|---|---|---|
| 用户提供的 4 个 AVI | 顺序解码 | 实际帧数等于容器声明；记录重复帧与时间异常，不隐去异常 |
| 相同录像/Engine，CV 与 IMM 配置 | blocking 回放 | processed=captured=输入帧数，failed/replaced=0；两组检测逐帧相同 |
| 回放 JSONL 与叠加视频 | 顺序检查 | frame_id 完整，时间递增，叠加视频可完整解码；IMM 概率合法 |
| 自动 ID 与候选框 | 生成复核材料 | 明确非真值，不计算没有人工真值支撑的 HOTA/IDF1/IDSW/召回 |

实测结果在执行后填写于 docs/real-recording-intake.md。

实测：四段全量解码 21,169 帧；两种跟踪配置全部 8 次正常退出、42,338 个输出帧可解码，检测逐帧相同，时间递增且无 blocking 丢帧。两个复核包各 90 帧，PNG 逐像素匹配源帧，JSON 候选框合法且无身份真值。详细记录见上述报告；真实身份指标仍待人工复核。

# 设计

原始 AVI 保持不变，计算 SHA-256 并顺序解码核对帧数、尺寸、容器媒体时间和相邻重复帧。输出 manifest.json 和带帧号的抽样联系表。没有独立采集时间戳时不声明真实 DXGI 采集无掉帧。

CV/IMM 使用同一 Engine、检测阈值、blocking 队列及原视频时间轴。逐帧验证检测相同、帧号完整、媒体时间递增、输出视频可解码。输出仅是自动候选；无身份真值时只报告工程计数，不推导身份准确率或召回。

单进程依次运行 GPU 回放，避免并发负载污染计时。任一进程失败保留日志，不覆盖源文件或已有输出目录。原始视频、回放产物保留本机 artifacts/docs，不加入代码提交。

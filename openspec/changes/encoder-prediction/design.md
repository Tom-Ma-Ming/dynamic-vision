# 已接收编码器外推与目标速度前馈

两个默认关闭的独立实验开关：encoder_extrapolation要求encoder_transport；velocity_feedforward要求encoder_compensation（后者已要求视角/增量执行模式）。不改变默认预测时距、PID增益、误差阈值及选择策略。

编码器外推只用最后两条已交付累计位置，以采样间隔求速度，向当前仿真时间作常速度外推。速度向量模长限制为actuator_max_speed（图像像素/秒）；最新样本过期、样本不足两条或两条间隔超过encoder_max_age_ms时不可用，继续禁发。历史观察配对仍用原始已收到的精确采样位置，不把预测当成传感器测量。外推对急停/变向不准确，必须保持实验属性。

前馈只用所选有效轨迹的已估计速度，经actuator_units_per_px转换后加到PID输出；总输出参与饱和及积分抗饱和。没有读取world_x、vx、未交付的encoder_x或未来真值。示例组合显式command_horizon_s=0，避免沿用100ms提前量又叠加速度前馈；这不是全局更改，消融单独覆盖仅去掉提前量的效果。

验收关注因果性、单位、饱和、默认兼容及全窗口误差。原TaskResult的SUCCESS是曾经满足稳定窗口的锁存结果，不能证明成功后始终保持；必须同时查看后续失踪和末段误差。

# 设计

每轨迹持有可选 ImmState，三个 [x,y,vx,vy] 高斯状态，单位 px、px/s；采集时间戳 ns 差值转秒用于预测。按时间相关对称 CTMC 混合先验；stationary 使用指数速度衰减，另两个模型采用不同过程噪声的 CV；Joseph 更新与对数观测似然更新概率。融合包含模型间均值差异项。

概率达到门槛的模型中最小创新距离参与门控/代价；保留全局一对一、身份歧义与生命周期。头转人物时三个模型同步平移锚点。扩大门控的身份风险需真实录像评估。

状态由原跟踪线程的 Track 值持有；predictAt 拷贝后计算，不引入线程或共享可变状态。dt=0 不变，负/非有限 dt 拒绝；开启时参数必填、有限且正值，门控概率不超过 1/3。创新协方差无效则抛异常，沿用回放异常传播与关闭逻辑。

开关缺省 false，关闭时保留 CV 算术和输出。开启后 JSONL 按需增加 mode_probabilities，顺序 [stationary,CV,maneuver]。回退为默认配置，无需迁移数据。模拟评分和延迟控制使用独立预测快照，原固定窗口与成功阈值不变。

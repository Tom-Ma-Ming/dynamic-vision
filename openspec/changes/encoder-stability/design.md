# 锁存结果之外的稳定证据

`TaskResult` 仍保存第一次终结事件。场景跑完后另外计算：

- 结束稳定：从最后一帧向前，连续满足“帧号不早于 success_after_frame、控制有效、归一化误差严格小于 epsilon_enter”的帧数达到 settle_frames。
- 持续稳定：结果为 SUCCESS，且锁存帧之后至少有 settle_frames 帧，这些帧全部控制有效且归一化误差不超过 epsilon_exit。最后一帧才成功时，后续帧数为 0，不能算持续稳定。

控制有效必须和 `control_gate == ready` 一致。摘要使用 schema 3；schema 2 没有这组证据。

每帧另外记录观测年龄、已接收编码器年龄、本帧命令飞行时间和滤波器速度。年龄在没有已发布样本时为 −1，没有生成命令的帧不填写飞行时间。这些字段只用于复盘，不参与控制计算。

命令飞行时间和已发出未执行位移在匀速稳态中相互抵消，不能单独消除比例控制的速度滞后。该校正不进入控制器。

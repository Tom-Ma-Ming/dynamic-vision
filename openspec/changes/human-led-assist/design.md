# 设计约束

实现状态见 tasks.md。下面的所有权和时间契约仍然有效。`assist_enabled` 只关闭人主导微调，不改变人工轨迹。`assist_defaults` 是实验参数的共享钩子。第二个人只存在于合成检测。`image_detector: pixel` 是色块闭环，不是 TensorRT。

输入包含时间戳、画面尺寸/ROI 变换、已选轨迹与测量年龄、当前时刻预测协方差、人工位移/接管标志和已交付执行反馈。仿真内部统一单调事件时钟，位移使用控制画面像素，速度 px/s、加速度 px/s²、时间 ns；设备单位转换作为单独标定边界，不与像素混用。

人工输入由外部脚本驱动，控制器只能观察已交付输入。控制器拥有辅助状态、积分和命令序号；执行器拥有物理状态；反馈接收器拥有合法已交付快照。真值只供渲染和独立评分，不能提前进入控制账目。线程或事件实现均不得改变此所有权和时间契约。

建议状态为 Disabled、Armed、Assisting、HumanOverride、Suspended。输出包含辅助增量、取消意图、状态和原因。区外/不可靠/人工接管/关闭进入无新输出状态、清除累积项并取消可撤销命令；无法撤销的在途动作独立记录。恢复须重新检查选择、区域、时效和人工释放条件。

区域进入/退出滞回、死区、单次位移/速度/加速度上限、人工让步阈值与恢复等待均显式配置并记录，数值先作为实验参数，产品体验待用户确认。不得仅通过图像运动猜测人工意图。目标参考点显式记录，不擅自更改头身策略。

保留旧模式用于诊断，增加显式辅助模式标识，禁止把旧输出重新解释为新验收。新补偿默认关闭；新辅助实现未通过前不改变旧运行结果。异常和关闭复用有界停止机制，取消与超时须有日志；未知状态退为不辅助。

# 设计
所有时间为模拟时钟纳秒。完整命令携带递增 ID、来源帧/轨迹、生成/到达/过期时刻及执行单位增量。新命令整体替换旧命令；过期或乱序命令不能改变状态。推进先应用从上一次推进起已生效的命令，再允许发布新命令，避免追溯执行。执行器采用速度限幅和量化余数；取消清余数。PID 输出为单位/秒，调用方按控制周期积分。

增量场景开启 incremental_control；传输队列在到达时交付完整命令，乱序由递增 ID 拒绝。delay_jitter_ms 使用独立随机流，不影响检测噪声。单位换算 actuator_units_per_px 明确配置；当前是二维光标/目标点模型，尚未接入视角反馈。量化余数在同轨迹替换时保留，取消、到期或换轨迹时清除。

view_feedback 模式执行量更新二维相机偏移，观察投影由世界位置减偏移生成，参考点固定图像中心；出视野不产生目标观测。当前为合成观察反馈，渲染与真实检测器仍待接入。该模式实验全 UNKNOWN，必须先解决自身动作反馈/运动估计与控制稳定性。

encoder_compensation 为模拟编码器实验：仅累计 advance 实际增量，下一帧更新前取反映射为背景位移，复用当前 tracker 的时间区间校验；没有真实设备反馈或未来真值输入。该模式默认关闭，方差 .25 为未标定实验值；不包含外部相机运动。

feedback_prediction 用本端命令和已收到反馈维护账目，EWMA(alpha=.2)估计生成到到达延迟，以剩余请求量近似在途位移；不读取未来到达安排。当前是即时反馈假设，实验误差有退化，保持默认关闭。

图像实验支持执行单位/px和独立亚像素渲染开关，用于分离执行量化和图像栅格化影响。该比例为模拟参数，不能当作硬件标定结果；固定素材六组仍未通过成功判据。

观察发布队列使用 capture/ready 两个模拟时刻，tracker按capture更新，控制predictAt(now)。encoder补偿分采集前时段与采集后已应用时段，不重复计算。固定观察延迟0～10000ms，过期观测不得控制。真实推理耗时暂为独立测量，不伪装为模拟时间。

发布抖动可导致乱序，按ready交付，旧capture拒绝；编码器位移使用累计值在实际接受时求差。有界结果缓冲溢出丢最旧capture。单服务者时间轴可用固定服务时长或检测回调返回的实测样本驱动，不能等同真实并发推理输入队列或壁钟运行。

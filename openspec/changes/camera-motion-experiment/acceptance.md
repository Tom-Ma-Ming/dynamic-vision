# 验收条件

| 场景 | 要求 |
|---|---|
| 已知平移纹理图、有独立运动前景 | 估计方向正确，平移误差 <0.5 px，前景被屏蔽 |
| 无纹理/跳时/分辨率变化/场景突变 | 可靠性检查拒绝，并记录原因；不应用错误补偿 |
| 已确认静止目标 + 背景平移 | CV/IMM、开关 ByteTrack 均保留原身份，补偿不会被当作目标速度 |
| 补偿时间区间失配/非有限数值 | 拒绝且快照不改变 |
| 关闭补偿 | 1000 帧稳定字段与旧基线一致，所有既有测试通过 |
| 真实录像 | 同源帧/检测对照，通过完整性与概率检查；诊断标签限制保留，不把单片段改善当普遍收益 |

实测通过 CPU 26/26、SDK 6/6、Python 20/20。关闭/开启各双跑 1000 帧，camera_motion 参与稳定语义哈希，耗时除外。两段原录像 10800 帧完整解码且检测一致；第二个诊断窗口 IDSW 24→15，第一个 HOTA 略降。质量门控通过率约 27%/39%，默认关闭，性能/真实镜头准确率未作为生产验收通过。详见 docs/camera-motion-experiment.md。

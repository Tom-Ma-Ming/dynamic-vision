# 设计

按相邻已处理帧估计背景从旧图到新图的像素平移；使用源时间戳 ns，不以推理耗时作 dt。检测框扩大后从两帧特征区域剔除，图像边缘与中心固定小区域也屏蔽。Shi-Tomasi 特征配合 LK 前后向光流；中位数位移、残差内点比例、数量、空间覆盖和最大位移共同门控。时间间隔过长、分辨率变化、弱纹理、场景突变等不可信结果返回明确原因；不凭空补偿。

用屏蔽图像的 Hanning 加窗相位相关提供平移初值，低响应或过大初值丢弃；随后使用两层（maxLevel=1）局部 LK 前后向校验。相位初值本身不能授权补偿，必须再通过背景特征共识和空间覆盖门控。浅金字塔减少大块移动前景污染粗层窗口。

估计器由回放推理线程持有，缓存上一已处理灰度图和掩码；latest 丢帧时仍使用真实处理间隔。跟踪更新先 predictAt 到当前采集时间，再将可信平移及位置方差同步加到所有 CV/IMM 模型。时间区间必须与当前跟踪快照一致，拒绝无效数值。平移不改变目标尺寸、ID、lastSeen 或头身偏移。

开启后速度倾向于扣除已补偿的背景平移；无法可靠估计时回退原观测更新，速度可能暂时混入镜头运动。因此不把它当世界坐标速度，不将未来预测宣称为已补偿未来镜头运动。位置仍在当前图像坐标系。关闭时不调用估计器、不增加 JSON 字段，原回放语义逐字段保持一致。

启用才输出 camera_motion 位移/方差/内点/原因和 camera_ms，单独统计开销。mot_ms 不包含背景估计，result_age 包含它。未知前景、视差、旋转、固定 HUD 都可能使平移失真；即使质量门控通过，也只属实验估计。失败沿用现有回放异常传播和队列关闭策略。

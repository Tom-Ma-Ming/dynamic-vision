# SIM-01 自建二维仿真闭环

## 目标

建立一个不接触游戏/桌面输入的二维仿真闭环：目标与相机运动可重放，检测由合成噪声/漏检/遮挡产生，现有 MOT 跟踪器做估计与预测，二维执行器接收预测位置并移动，仿真器独立给出 `SUCCESS / FAILED / UNKNOWN` 事件。用于 T12 和 TRACK-04 的受控场景基线。

## 范围

- 二维世界与屏幕坐标，目标运动：匀速、急停、变向、蹲下、遮挡、相机平移。
- 合成 person/head 观测：高斯噪声、漏检、遮挡、可选误检。
- 复用 `mot::Tracker` 做估计/预测；执行器有最大速度和命令延迟。
- 位置闭环：归一化误差、连续 N 帧、协方差、观测年龄、滞回进入/退出。
- 结果闭环：SUCCESS/FAILED/UNKNOWN，记录终止帧与失败类别；不做无限重试。
- 指标：MAE/P95、稳定时间、超调、遮挡恢复、观测年龄分位数、检测/误检/漏检、ID 切换、成功率；按场景和运动类型分层。
- 输出 JSONL/JSON/Markdown；`sim_test` 覆盖 T12。

## 非目标

- 不接游戏、不注入键鼠、不控制外部设备。
- 不模拟真实相机 SDK、不追求照片级渲染。
- 不替代真实录像上的 MOT 指标；仿真结果单独标注。
